# images/

Locally hosted image assets.

- `logo.jpg` — full MOAB Música y Arte logo (used in the home page hero).
- `logo-icon.png` — emblem-only crop of the logo (header and footer badges).
- `favicon.png` — 64×64 emblem used as the site favicon.

All other images are still hotlinked from the original organization's
WordPress media library (moabacademiademusica.com). To make this site fully
independent, download those assets into this folder and update the `<img>` /
`<figure>` `src` attributes in `index.html` and the files under `pages/` to
point here instead (e.g. `images/team/cesar-garcia.jpg`).
