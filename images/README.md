# images/

All images used by the site, hosted locally.

- `logo.jpg` — full MOAB Música y Arte logo (home page hero).
- `logo-icon.png` — emblem-only crop of the logo (header and footer badges).
- `favicon.png` — 64×64 emblem used as the site favicon.
- `team/` — instructor portraits (About page).
- `programs/` — program photos (Programs page, page heroes).
- `gallery/` — general class and student photos (Home and About pages).
- `events/` — event flyers (Events page).
- `icons/` — feature icons (About page).
- `testimonials/` — reviewer avatars (Home page).
- `support/` — donation QR code (Support page).

Photos were originally copied from the previous WordPress media library; large
ones were resized to a max of 1600px and re-compressed.
